GitHub einrichten

Nur für den Webmaster, nur einmal nötig (und wenn der Zugangscode abläuft). Danach speichern „Save“ und „Einträge übernehmen“ die Datei run.js direkt auf GitHub – von jedem Computer aus, nach Eingabe des Webmaster-Passworts.

  1. Bei GitHub einen Zugangscode anlegen:
    Zugangscode bei GitHub anlegen
    • Token name: z. B. „ACH3 Website“
    • Expiration: z. B. 1 Jahr (danach hier neu einrichten)
    • Repository access: „Only select repositories“ → Angeles-City-Hash-House-Harriers
    • Permissions → Repository permissions → Contents: „Read and write“ (sonst nichts)
    • Unten auf „Generate token“ klicken und den Code (beginnt mit github_pat_) kopieren.
  2. Den Code einfügen und ein neues Webmaster-Passwort festlegen. Mit diesem Passwort wird der Code verschlüsselt.
    • Mindestens 12 Zeichen, am besten ein Satz aus mehreren Wörtern.
    • Nicht das Log-In-Passwort und kein Passwort aus pw.js – die sind öffentlich lesbar.
  3. Fertig – github-config.js ist auf GitHub gespeichert. Bitte auch im Website-Ordner auf dem Computer speichern (vorhandene Datei ersetzen), damit sie beim nächsten Hochladen von Hand nicht mit einer alten Version überschrieben wird.

Moderator-Zugang

Moderatoren (in pw.js mit moderator: true) speichern ihre Einträge direkt in die run.js auf GitHub. Dafür wird der Zugangscode zusätzlich mit einem Moderator-Passwort verschlüsselt, das der Webmaster hier festlegt und den Moderatoren mitteilt. Das Webmaster-Passwort bleibt geheim.

Mindestens 12 Zeichen, nicht gleich dem Webmaster-Passwort und kein Passwort aus pw.js. Wird oben GitHub neu eingerichtet, muss auch das Moderator-Passwort neu gespeichert werden. Soll ein Moderator nicht mehr veröffentlichen können: ein neues Moderator-Passwort festlegen oder den Zugang entfernen.

Der Code steht nur verschlüsselt auf der Website. Ohne das Webmaster-Passwort ist er nutzlos. Das Passwort nirgends aufschreiben, wo andere es sehen. Wird es doch bekannt: Zugangscode bei GitHub löschen (Settings → Developer settings → Personal access tokens) und hier neu einrichten.
